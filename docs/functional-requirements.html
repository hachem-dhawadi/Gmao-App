Module 01
Authentication & Access Control
Identity, session management, and account security
Platform
Registration
  • User self-registration with company creation — company name, user name, email, and password
  • OTP email verification — 6-digit code sent to email; account inactive until verified
  • Company account placed in pending state until approved by a superadmin
Login & Sessions
  • Email + password login with Sanctum token-based authentication (Bearer token)
  • Google OAuth sign-in — links to existing account or creates new one
  • Token stored in encrypted secure storage on mobile (expo-secure-store)
  • Automatic 401 logout — on expired or revoked token, app clears session and redirects to login
Password Recovery
  • Forgot password flow — enter email → receive reset link → set new password
  • Change password while logged in — requires current password confirmation

Module 03
Multi-Tenancy & Company Management
Complete data isolation across companies
Platform
  • Each company has fully isolated data — members, assets, WOs, inventory, etc. are never shared across companies
  • All API requests scoped by X-Company-Id header — middleware enforces membership
  • Sites — each company can have multiple physical sites; assets and members are linked to sites
  • Warehouses — each company can have multiple warehouses for inventory stock tracking

Module 05
Asset Management
Full lifecycle tracking of physical equipment and machinery
Core CMMS
Asset Records
  • Create, edit, archive, and delete assets with name, code, serial number, description, location, and site
  • Asset types / categories — organize assets into custom hierarchical types
  • Assign assets to a site and a team

Module 06
Work Orders
The operational core — create, track, and close maintenance tasks
Core CMMS
Work Order Lifecycle
  • Create WOs with title, code (auto-generated or manual), priority, asset, due date, estimated time, description
  • Priority levels: Low · Medium · High · Critical
  • Full status workflow: open → in_progress → on_hold → completed → pending_approval → approved / rejected
  • Approval workflow — completed WOs submitted for manager/admin review; approve or reject with reason
  • Overdue detection — WOs past their due date flagged and owners notified
  • Status history log — every status change recorded with timestamp and actor
  • Activity log — full audit trail of all actions on the WO
Assignment & Collaboration
  • Assign WOs to one or more members (permission-gated: work_orders.assign)
  • Comments — team members post updates; supports @mention to notify specific people
  • Checklist items — task-level checkboxes, individually toggleable with progress tracking
Evidence & Time Tracking
  • File attachments — upload photos, PDFs, documents directly to a WO (camera, gallery, or file browser)
  • Work logs — record labor time (minutes), labor cost ($), and notes per session; edit and delete own logs
  • Work log summary bar — total hours and total cost aggregated across all logs
  • Parts used — record inventory items consumed (item, warehouse, quantity, used vs scrapped); deducts from stock
Failure Analysis
  • Record failure code (electrical fault, mechanical failure, wear & tear, operator error, lack of maintenance, manufacturing defect, environmental, unknown)
  • Record root cause (inadequate maintenance, operator error, design flaw, normal aging, overload, external factor, unknown)
  • Free-text resolution notes
  • Visible and editable when WO status is in_progress or completed
Views & Filtering
  • List view — search, filter by status / priority / assignee / site / asset; sort; paginate
  • Kanban board view — drag WO cards between status columns
  • Filter by "My Work Orders" — show only WOs assigned to the current user
🔄
Module 07
Preventive Maintenance
Scheduled maintenance plans that auto-generate Work Orders
Core CMMS
  • Create PM Plans with name, asset, frequency, estimated duration, assigned member, and description
  • Frequency options: Weekly · Monthly · Quarterly · Bi-Annual · Annual
  • PM Plan statuses: draft · active · inactive · overdue
  • PM Tasks — define a checklist of recurring tasks attached to each PM plan
  • Automatic WO generation — a scheduled cron command (TriggerPmPlans) creates a new Work Order when a PM plan comes due
  • PM-to-WO linkage — generated WOs are traceable back to the originating PM plan
  • Next due date tracking — system calculates and displays when each PM plan is next due
  • PM Plan list with search, status filter, priority filter, and pagination
  • PM Plan detail shows history of all generated WOs
  • Overdue PM Plans flagged and admins/managers notified
📥
Module 08
Maintenance Requests
Any user can report a problem; admins review and convert or reject
Core CMMS
  • Any authenticated user can submit a maintenance request — title, description, asset, priority
  • Request statuses: pending · converted · rejected
  • Convert to Work Order — admin/manager reviews request and promotes it to a full WO (preserves asset, description, priority)
  • Reject with reason — admin/manager rejects the request; requester is notified
  • List view with status tabs (All / Pending / Converted / Rejected) and search
  • New request submission fires notification to all admins and managers

Module 09
Inventory & Warehousing
Parts, materials, and stock level tracking across warehouses
Operations
  • Create, edit, and delete inventory items — name, code, barcode, unit, unit cost, description, minimum stock level
  • Attach images to items
  • Multi-warehouse stock tracking — stock quantity tracked per item per warehouse independently
  • Stock movements — record receipts (in), issues (out), and manual adjustments with type, quantity, and notes
  • Low stock alert — when stock at any warehouse falls to or below min_stock, notify all admins and managers
  • Parts used in WO — recording a part on a WO automatically issues stock from the selected warehouse
  • Item list with search, low-stock filter, and pagination
  • Item detail shows stock by warehouse, movement history, and linked WOs
  • Warehouse CRUD — create and manage physical storage locations
  • Barcode field on items — scannable for quick lookup
